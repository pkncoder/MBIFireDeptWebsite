# Middle Bass Island Fire Dept. Website

This repository is to store the code for the Middle Bass Island fire department's website.

## Overview

This website is meant to give information of the fire department, recognition to the officers, and the ability to volunteer or donate.

This site is created in contribution by Kia Preston (@pkncoder).

## Hosting

This site is hosted and maintained by AWS under Harold Preston III's (@hpreston), and does not have a domain yet.
